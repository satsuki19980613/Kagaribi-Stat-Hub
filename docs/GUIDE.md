# 使い方の詳細

[README](../README.md) の各機能の詳しい中身と、スタッツの指標の定義。

## 記録

- 日付を選び、参加したメンバーの順位（1〜6位）をタップして保存。得点は順位から自動で決まる
  - 1位 +5 / 2位 +3 / 3位 +2 / 4位 +1 / 5位 ±0 / 6位 −1（公式の個人ポイント）
- 記録した人が参加、記録しなければ不参加。1部／2部の指定は任意
- 1人 1日 1件（クラブマッチは 1日 1回まで）。既に記録がある日を開くとその内容が入っていて、そのまま修正・取り消しができる（二重記録はできない）
- 「記録履歴」から日付ごとの一覧・1件ずつの削除・その日の修正

## メンバー情報登録

- 人数に上限はなく、代走のメンバーも登録できる。外したメンバーはアーカイブに残り（記録は保持）、いつでも戻せる。完全削除はアーカイブ済みのメンバーだけ
- 参加回数（クラブマッチ）：登録時にこれまでの回数を入れ、以降は記録するたびに自動で +1
- 基本スタッツ（優勝回数・VPIP・参加ハンド数）は任意。入れた日の値として履歴に残る

## スタッツビュー

- グラフはメンバー平均（点線）を基準に、強調したメンバー（最大 8 人）を重ねて表示
- シーズン内：累積ポイント推移のグラフ、メンバー別の 合計pt・平均pt・加点率・1位率・平均順位・参加数・生存ターン数（並べ替え可）
- シーズン推移：上の各指標のシーズンごとの推移（グラフと表）、クラブ合計ポイント
- 行をタップするとメンバーの詳細（順位の分布・シーズン別・最近の記録）
- クラブ順位 · 上位30：燎と上位 30 クラブの累計を比べるグラフ（燎・右上のプルダウンで選んだクラブ・上位 30 平均の点線）と、最新の順位表

### 指標の定義

| 指標 | 定義 |
| --- | --- |
| 平均ポイント | 合計pt ÷ 参加数 |
| 加点率 | 1〜4位（+1 以上）の回数 ÷ 参加数 |
| 1位率 | 1位の回数 ÷ 参加数 |
| 生存ターン数 | 参加ハンド数 ÷ (参加回数 × VPIP[%]) |

生存ターン数は、同じ日に入力した 参加回数・VPIP・参加ハンド数 だけで計算する（自動カウントの参加回数は混ぜない。
スタッツを更新しない期間があっても、値は最後に入力した時点のまま正しく残る）。
シーズン内の表ではシーズン末時点で最新の値、シーズン推移ではそのシーズン中に入力した値を使う。

## シーズン設定

シーズンは記録した日付の月から自動判定（S31 = 2026/10/3〜10/31、以降 1 か月ごとに +1）。
急な短縮・延長・休催があったときは、シーズンごとに期間と開催日（火・木・土）を手で直せる。

## バックアップ

- 端末内の履歴：記録・メンバー・シーズン設定を変えるたびに全体のコピーを自動で残す（直近 30 件 + それより前は 1 日 1 件を 60 日ぶん）。
  「バックアップ」画面から好きな時点に戻せる（戻す前の状態も履歴に残る）
- ファイルへの自動保存（PC の Chrome / Edge）：一度保存先の JSON ファイルを選ぶと、変更のたびに自動で書き出す。
  ブラウザを開き直したときはメニューの「再開」を 1 回押す（ブラウザの決まりで、書き込みの許可を出し直す必要があるため）
- 保存領域の保護（`navigator.storage.persist()`）を起動時に頼む
- 手動の書き出し・読み込み（JSON、読み込みは全置き換え）

## クラブ順位（上位30）

- 置き場所：このリポジトリの `public/data/clubs.json`。アプリと一緒に配られ（`data/clubs.json`）、`main` に入ってデプロイされると届く
- アプリは起動時・ネットにつながったとき・画面に戻ってきたとき（10 分おき）に読み直し、端末に残す（オフラインでは前回の内容）
- 取り込み：Claude Code で集計ポストのスレッドをコピペして「順位を取り込んで」と頼むと、
  [.claude/skills/club-ranking](../.claude/skills/club-ranking/SKILL.md) の手順で読み取り・前節との突き合わせ・`main` への反映まで行う
  （手で行う場合は `npm run ranking -- --file public/data/clubs.json --in <貼り付けた文章.txt> --dry` で確認してから `--dry` を外す）
- 燎は上位 30 に入った節は公式の値、圏外の節はアプリの記録の合計で線をつなぐ
