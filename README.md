# Kagaribi Stat Hub

ポーカーチェイスのクラブ「燎」のクラブマッチ戦績を記録・集計するローカル Web アプリです。
記録はすべて端末のブラウザ（IndexedDB）に保存され、どこにも送信しません。
デザインは [kagaribiICM](https://github.com/satsuki19980613/kagaribiICM)（crystal / square・焚き火背景・ライト／ダーク）と同じです。

## 機能

- **記録**: 日付を選び、参加したメンバーの順位（1〜6位）をタップして保存。得点は順位から自動で決まります
  - 1位 +5 / 2位 +3 / 3位 +2 / 4位 +1 / 5位 ±0 / 6位 −1（公式の個人ポイント）
  - 記録した人が参加、記録しなければ不参加。1部／2部の指定は任意
  - 1人 1日 1件（クラブマッチは 1日 1回まで）。既に記録がある日を開くとその内容が入っていて、そのまま修正・取り消しができます（二重記録はできません）
  - 「記録履歴」から日付ごとの一覧・1件ずつの削除・その日の修正
- **メンバー情報登録**: 有効メンバーは最大 20 人。外したメンバーはアーカイブに残り（記録は保持）、いつでも戻せます。完全削除はアーカイブ済みのメンバーだけ
  - 参加回数（クラブマッチ）: 登録時にこれまでの回数を入れ、以降は記録するたびに自動で +1
  - 基本スタッツ（優勝回数・VPIP・参加ハンド数）は任意。入れた日の値として履歴に残ります
- **スタッツビュー**
  - シーズン内: 累積ポイント推移のグラフ、メンバー別の 合計pt・平均pt・加点率・1位率・平均順位・参加数・生存ターン数（並べ替え可）
  - シーズン推移: 上の各指標のシーズンごとの推移（グラフと表）、クラブ合計ポイント
  - 行をタップするとメンバーの詳細（順位の分布・シーズン別・最近の記録）
- **シーズン設定**: シーズンは記録した日付の月から自動判定（S31 = 2026/10/3〜10/31、以降 1 か月ごとに +1）。
  急な短縮・延長・休催があったときは、シーズンごとに期間と開催日（火・木・土）を手で直せます
- **バックアップ**: JSON で書き出し・読み込み（読み込みは全置き換え）
- ライト／ダーク、PWA（インストール可・オフライン動作）

### 指標の定義

| 指標 | 定義 |
| --- | --- |
| 平均ポイント | 合計pt ÷ 参加数 |
| 加点率 | 1〜4位（+1 以上）の回数 ÷ 参加数 |
| 1位率 | 1位の回数 ÷ 参加数 |
| 生存ターン数 | 参加ハンド数 ÷ (参加回数 × VPIP[%]) |

生存ターン数は、同じ日に入力した 参加回数・VPIP・参加ハンド数 だけで計算します（自動カウントの参加回数は混ぜません。
スタッツを更新しない期間があっても、値は最後に入力した時点のまま正しく残ります）。
シーズン内の表ではシーズン末時点で最新の値、シーズン推移ではそのシーズン中に入力した値を使います。

## 起動（Windows / macOS / Linux 共通）

[Node.js](https://nodejs.org/) 20 以上が必要です。

```bash
npm install
npm start
```

ビルドしてブラウザで `http://localhost:4181` を開きます。同じネットワークのスマホから使う場合は `npm run preview -- --host` で表示される URL を開いてください。

開発用（ホットリロード）は `npm run dev`（`http://localhost:5181`）。

### デモ版

```bash
npm run build:demo
npx vite preview --outDir dist-demo
```

サンプルデータ（12 人・S31〜S33）が入ったデモ版を `dist-demo/` に作ります。「今日」を 2026/12/17 として表示し、
S32 は「急遽 1 日短縮・11/17 休催」の手動修正の例になっています。メニューの「サンプルに戻す」で初期状態へ戻せます。

| コマンド | 内容 |
| --- | --- |
| `npm test` | 単体テスト（Vitest） |
| `npm run typecheck` | 型チェック |
| `npm run build:demo` | サンプルデータ入りのデモ版を `dist-demo/` にビルド |
| `npm run icons` | `public/icon.svg` から PWA アイコン PNG を生成 |

## 構成

```
src/
  domain/     純ロジック（得点・シーズン判定・集計・1日ぶんの保存計画・バックアップ）とテスト
  data/       IndexedDB の保存層
  screens/    画面（メニュー・記録・履歴・メンバー・スタッツ・シーズン設定・バックアップ）
  components/ 共通 UI・SVG チャート・焚き火背景
  demo/       デモ版のサンプルデータ
```
