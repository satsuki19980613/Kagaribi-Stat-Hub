# クラブ順位（上位30）の取り込み

アプリ（Kagaribi Stat Hub）は、アプリと一緒に配られる `data/clubs.json`（このリポジトリの `public/data/clubs.json`）を
ネットにつながったときに読み、スタッツビューの「クラブ順位 · 上位30」とメンバーのグラフの比較に出す。
この手順で `public/data/clubs.json` に節を足し、`main` に入れる。`main` に入ると Cloudflare が 1〜2 分で配り直す（DEPLOY.md）。

## 1. ポストを受け取る

- クラウドのセッションからは X（x.com）を読めない。ユーザーに、集計ポストの**スレッド全体**をコピペしてもらう（スクショでもよい）。
  雑なコピペでよい: 名前・@ID・時刻・閲覧数・「Discover more」などの行は無視され、何節ぶんをまとめて貼っても見出しごとに分けて読む。
- 行の形（2 列目は**累計**）:
  - 第1節: `順位 累計 [メダル] クラブ名`（例 `1 56 🥇【γ】`）。前節も得点も無いので、得点 = 累計として残す
  - 第2節以降: `順位(前節の順位) 累計 +その節の得点 [メダル] クラブ名`（例 `1(1) 138 +50 🥈 SB from リンプして時雨`）
  - 圏外から入ったクラブ: `10(外) 76 GOGOマフィン`（得点は書かれない。null のまま残す）
  - 同点は同じ順位が並ぶ（`3 44 Black Box` / `3 44 #41`）。そのため 1 節が 30 クラブより多いことがある
- 見出し `シーズン31 第3節` からシーズンと節を読む。同じ節がスレッドの「おすすめ」などで 2 回貼られていても 1 つにまとめる。
- スクショのときは、画像から上の形の行に書き起こしてから次へ進む（クラブ名は 1 文字ずつ確かめる）。

## 2. 読んで確かめる（まだ書き込まない）

貼られた文章をスクラッチパッドに `paste.txt` として保存し（Write ツールでそのまま）、このリポジトリで:

```sh
npm ci   # node_modules が無ければ
npm run --silent ranking -- --file public/data/clubs.json --in <scratchpad>/paste.txt --dry
```

- 見出しが無い（1 節ぶんだけの）ときは `--season 31 --round 3` を足す。
- 第N節は、そのシーズンの N 番目の開催日（アプリのシーズン設定で決まる）。
- 出力の「読めなかった行」「確認してほしいこと」「同じ節に違う値で 2 回出てきたもの」を 1 つずつ見る:
  - クラブ数が 30 より少ない → スレッドの続きが欠けていないか、ユーザーに聞く（同点で 30 より多いのは正常）。
  - `前節 X + Y ≠ Z` や前節の順位の食い違い → たいていはクラブ名の表記ゆれ（全角・半角・小さい字・空白・絵文字）。
    累計が合うことを確かめてから、多くの節で使われている方の表記に paste.txt（必要なら clubs.json の前の節も）を合わせて読み直し、直したことをユーザーに伝える
    （例: 第1節だけ「すとろべりー☆ていると」、第2節以降は「すとろべりー☆てぃると」→ 後者にそろえた）。本当に元のポストの数字が合わないなら、そのままにしてユーザーに伝える。
  - 「前節のデータがない」→ 前の節を取り込み忘れていないか、ユーザーに聞く（抜けた節はグラフが途切れるだけで、壊れはしない）。
  - 「圏外から入ったとあるが、前節のデータでは N 位」→ 名前の表記ゆれか、ポストの誤り。ユーザーに伝える。
- エラーが出たら書き込まれない。直してから読み直す。

## 3. 書き込んで main に入れる

1. `--dry` を外して同じコマンドを実行する（同じ節が既にあれば置き換わる）。`npm test` も通ることを確かめる。
2. セッションの作業ブランチにコミットして push する（メッセージ例: `Import club ranking S31 round 4`）。
3. `main` 向けの PR を作り、そのままマージする。順位の取り込みはすぐ反映してほしい、とユーザーが決めている。
   ほかの変更が同じ PR に混ざるときは、マージ前にユーザーに確かめる。
4. マージ後 1〜2 分で Cloudflare が配り直す。アプリは次に開いたとき（ネットにつながっていれば）新しい順位を読む。

## 4. 報告する

- シーズン・節、クラブ数、燎の順位と累計（圏外ならそう書く）、1 位のクラブと累計。
- 直した表記ゆれ、確認してほしいことが残っていればその内容。
- PR のリンク（マージ済みであること）。
